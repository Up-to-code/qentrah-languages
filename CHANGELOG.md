# Changelog

## 0.2.0 — 2026-09-26

- Dedicated Languages menu and top-toolbar icon, with translation management outside the editor.
- Searchable, paginated pages/posts list; open existing translations, create drafts and link existing content.
- Source-review acknowledgement and language assignment in the manager; retains existing relationships.
- Language locale is optional; EN/AR/ES input normalizes to lowercase.
- Illustrated EN/AR/ES/FR HTML manuals generated with JavaScript, downloadable from releases.
- Public GPL repository and Qentrah product/documentation links.

Initial standalone multilingual preview.
